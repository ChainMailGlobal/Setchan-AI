Pomaik'AI's five-model AI C-suite, seated in a Switch room, founding Setchan AI.
Not a mixture of experts. A mixture of specialists.

Five different open models from five labs (Hermes 4 — Nous Research; Kimi-K3 —
Moonshot; Nemotron 3.5 Super VL — NVIDIA; Muse Spark Open — Meta; GLM-5.2 —
Z.ai), running on the Nebius Token Factory API, deliberated as a C-suite in a
private Switch (Mattermost) channel chaired by founder Daniel Kaneshiro,
directing by voice. The board distilled one master prompt and handed it to a
coding agent (Claude Code, seated in the room as "Builder"), which is building
Setchan AI: an offline-first navigator for family caregivers in skilled-nursing
stays. First flow: the Shift Change Checklist (Arrival phase). Stack: Vite +
React + TypeScript + Dexie + Tailwind. No backend, no accounts, no PHI —
fictional demo case only (caregiver Sarah, resident Maria R.). Founding
session, Sat Nov 7 2026: call to order 7:36 AM HST, master prompt handed to
Builder 8:00 AM HST, total session cost $0.087 under a $5/day hard cap.
